# ⚡ PWR Neon

Telegram Mini App: кейсы подарков, скины CS и тир-кейсы под одним балансом ⭐, 30+ игр, боевой пропуск, задания, вывод скинов в Steam.
База — NePridymal (описание ниже), к ней добавлены кейсы и пропуск из PWR SKINBOX и тир-кейсы.

## Что добавлено поверх базы

| Блок | Где в коде | Суть |
|---|---|---|
| Кейсы скинов CS | `server/economy.py`, `server/pwr/data.json` | 12 кейсов, шансы и цены из SKINBOX; цена скина в ⭐ = цена в $ × `pwr.usd_coins` |

| Пуши по событиям | `server/pushes.py` | 30 событий (кейс готов, серия сгорает, подарок в сумке, турнир, задания…), по 2–4 текста и карточка-картинка; общий лимит `[push]` в `settings.toml` — 2 в сутки; статистика `GET /admin/pushes`, образец себе `POST /admin/pushes/test {send:true}`; надпись на карточках — имя бота или `BRAND` |

## Запуск в бою (Railway)

База и скачанные картинки подарков лежат на постоянном диске `/data` (`DB_PATH=/data/game.db`, `ASSET_CACHE=/data/assets`).
Чтобы демо стало рабочим ботом, задай переменные сервиса:

| Переменная | Что это | Обязательна |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | да |
| `BOT_USERNAME` | имя бота без @ | да |
| `ADMIN_IDS` | твой Telegram ID (несколько — через запятую) | да |
| `DEV` | `0` — вход только через Telegram, бот начинает принимать оплату | да |
| `PWR_CHANNEL` | `@канал` для задания «Подпишись»; бот должен быть админом канала | нет |
| `FREE_CHANNELS` | каналы и чаты для первого бесплатного кейса, через запятую: `@канал` или `id\|ссылка\|название`; бот должен быть админом в каждом | нет, без них первый бесплатный кейс без условий |
| `ADSGRAM_BLOCK` | ID блока Rewarded в Adsgram | нет |
| `ADS_SECRET` | любая длинная случайная строка; в Adsgram в Reward URL: `https://<домен>/np/api/pwr/ads/reward?userid=[userId]&secret=<ADS_SECRET>` | нет |
| `MARKET_KEY` | API-ключ market.csgo.com (аккаунт площадки в USD или RUB, на балансе деньги; бот пишет админам, когда баланс ниже `withdraw.low_usd`) | нет, без него вывод выключен |
| `TONNEL_AUTH` | сессия площадки Tonnel для покупки коллекционных подарков: строка `web-initData` из хранилища сайта market.tonnel.network (на балансе площадки должен быть TON) | нет, без неё в кейсах только обычные подарки |
| `TONNEL_PROXY` | прокси для запросов к Tonnel, `http://логин:пароль@адрес:порт`. С адреса Railway площадка не отвечает (блокировка Cloudflare), поэтому для коллекционных подарков прокси обязателен | нет |
| `CRYPTOPAY_TOKEN` | токен приложения Crypto Pay: @CryptoBot → Crypto Pay → Create App | нет, без него пополнение криптой скрыто |
| `GIFT_ASSETS` | `off` — не ходить за картинками подарков наружу, отдавать только скачанное на диск | нет |

Обычные подарки Telegram игрокам дарит сам бот со своего баланса Telegram Stars (туда приходят покупки) — ключей для этого не нужно.
Состояние цен, балансы бота и площадки и заявки на ручную проверку: в игре плитка «Настоящие» → внизу «Для админа».

После запуска: в игре открой админ-панель → «Продажи» и включи продажу ⭐, VIP и сундука. В @BotFather укажи адрес Mini App: `https://<домен>/np/`.

Картинки подарков Telegram скачиваются с открытого `api.changes.tg` один раз и остаются на диске. Картинки скинов — со Steam CDN.
Арт интерфейса и обложки тир-кейсов сгенерированы в Higgsfield и подтягиваются при сборке (`tools/fetch_art.py`); не скачались — работают запасные обложки из `tools/tier_covers.py`.

## 🚀 Быстрый старт (5 минут)

### 1. Создай бота
Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → скопируй **токен** (`123456789:AA...`).

### 2. Скачай игру
`git clone https://github.com/leath0r/NePridymal.git` — или на странице репозитория **Code → Download ZIP** и распакуй.

### 3. Запусти

| Система | Что сделать |
|---|---|
| **Windows** | двойной клик по **`start.bat`** |
| **Linux** (VPS) | в терминале: `sudo ./start.sh` — root нужен для портов 80/443 (сертификат на IP) |
| **macOS** | в терминале: `./start.sh` |

### 4. Ответь на три вопроса
- **Токен бота** — вставь из шага 1.
- **Твой Telegram ID** — чтобы получить админ-панель (узнать у [@userinfobot](https://t.me/userinfobot)). Можно пропустить.
- **Включить автозапуск?** — Enter = да: игра будет работать в фоне и сама стартовать после перезагрузки (окно можно закрыть).

### 5. Играй
Открой своего бота в Telegram → кнопка **«Играть»** внизу. Готово 🎉

> Без автозапуска окно со скриптом не закрывай — пока оно открыто, игра работает. Остановить — `Ctrl+C`.
> Следующие запуски — тот же `start.bat` / `./start.sh`, вопросов больше не будет.

### Автозапуск
| | Включить | Выключить | Где лог |
|---|---|---|---|
| **Linux** (systemd) | `venv/bin/python run.py --install` | `… run.py --uninstall` | `data/logs/run.log` |
| **macOS** (launchd) | `venv/bin/python run.py --install` | `… run.py --uninstall` | `data/logs/run.log` |
| **Windows** (Планировщик, при входе) | `venv\Scripts\python run.py --install` | `… run.py --uninstall` | `data\logs\run.log` |

`run.py --status` — работает ли автозапуск. `run.py --install --dry-run` — показать, что будет установлено, ничего не меняя.
На Linux от root ставится системная служба, от обычного пользователя — пользовательская (живёт и без входа в систему).

## 🧩 Что умеет первый запуск сам

- ставит Python, если его нет (Windows — через winget; Linux/macOS — через системный пакетный менеджер: apt, dnf, pacman, brew и т. п.);
- создаёт окружение и ставит зависимости (`requirements.txt`);
- **сам делает HTTPS без домена** (Telegram открывает игры только по https):
  - есть публичный IP (любой VPS) → получает бесплатный сертификат Let's Encrypt **прямо на IP** и продлевает его сам —
    игра по постоянному адресу `https://ТВОЙ-IP/np/`, порты 80 и 443;
  - нет публичного IP (дома за роутером) → поднимает бесплатный туннель Cloudflare (адрес меняется при перезапуске);
- собирает фронтенд и ставит боту кнопку «Играть» с актуальной ссылкой;
- создаёт базу `data/game.db`;
- **следит за сервером**: упал или перезапустился после импорта базы — поднимает снова за секунды;
- **бэкап базы каждые 6 часов** в `data/backups/` (хранятся 28 последних ≈ неделя).

**Требования:** Windows 10/11, Linux или macOS · Python 3.11+ · интернет · ~200 МБ RAM.

## ⚙️ Настройки — `settings.toml`

Все шансы и экономика в одном файле, каждая строка подписана по-русски:

```toml
[games]
edge = 0.96            # кубик, лимбо, башня — возврат игроку (96%)
upgrade_edge = 0.92    # апгрейд: шанс = ставка / цель × 0.92
dogs_scale = 0.405     # пёсики (≈ 98,4% возврата)
slots_rtp = 0.92       # слоты

[start]
start_stars = 5000     # звёзд новому игроку
```

**Шансы игр проще менять прямо в игре:** Админка → вкладка **«Шансы»**. Там у каждой игры свой % возврата
и прибыль казино по ней за 7 дней. Изменение действует сразу, без перезапуска, и важнее файла.
«Сбросить» возвращает значение из `settings.toml`. Менять может только владелец, остальные админы только смотрят.

Поменял число в файле → сохранил → перезапустил игру. Опечатка не уронит игру — возьмутся значения по умолчанию,
а в окне появится предупреждение.

> **Возврат игроку** `0.96` = на дистанции игрокам возвращается 96% ставок, казино оставляет 4%.
> Не ставь `1.0` и выше — казино начнёт раздавать звёзды.

## 🛠 Админ-панель

Значок замка 🔒 в шапке игры, рядом с профилем (виден только админам):
обзор и экономика, **шансы всех игр**, продажи за Telegram Stars, поиск игроков, начисление/списание звёзд, бан,
выдача подарков и ключей, рассылка, журнал действий, акции и ивенты, закрытие игр.

**Выдать админку другу:** Админка → Игроки → игрок → «Сделать админом». Выдавать и снимать может только владелец
(ID из `.env`).

**База (только владелец):** Админка → «База».
- **Экспорт** — бот присылает тебе в личку свежую копию базы `game-….db.gz` (игра не останавливается).
- **Импорт** — выбираешь `.db` или `.db.gz` (из экспорта или `data/backups/`): файл проверяется на целостность,
  текущая база сохраняется в `backups/`, затем заменяется, игра перезапускается (~10 с).

**Счётчик FPS** — в углу экрана у админов: средний FPS и самый долгий кадр. Тап — спрятать, открыть админку — вернуть.

## 🏠 Запуск дома без белого IP (Orange Pi, Raspberry Pi, старый ноутбук)

Игру **не обязательно** держать на платном VPS. Подойдёт любой компьютер дома: одноплатник
(Orange Pi Zero 3, Raspberry Pi), мини-ПК или старый ноут. Белый (публичный) IP при этом **не нужен**.

### Почему бот работает без адреса, а игра — нет
Это два разных куска, и путаница именно здесь:

- **Бот** (сообщения, кнопки, команды) ходит к Telegram **сам, наружу** (long polling). Ему всё равно,
  за каким роутером он стоит, — белый IP ему не нужен и никогда не был нужен. Поэтому «простые боты»
  запускаются где угодно без настроек.
- **Mini App** (сама игра) — это **веб-страница**, которую Telegram открывает внутри приложения, когда игрок
  жмёт «Играть». Телефон игрока должен **загрузить** эту страницу с твоего сервера по HTTPS. Чтобы телефоны
  снаружи могли достучаться до компьютера, стоящего дома за роутером, его надо «показать» в интернет.

Этим и занимается **бесплатный туннель Cloudflare** — он сам пробивает канал наружу (ровно как бот к Telegram),
и белый IP не требуется.

### Вариант по умолчанию — ничего не делать
`start.sh` видит, что белого IP нет, и сам поднимает бесплатный туннель. Игра сразу доступна по HTTPS.

Единственная особенность — адрес туннеля (`что-то.trycloudflare.com`) **меняется при каждом перезапуске**.
Что это значит на практике:

- ✅ **Не ломается:** вход через кнопку «Играть» в меню бота. Бот переставляет кнопку на новый адрес при каждом
  старте сервера, так что игроки всегда попадают куда надо. Делать руками ничего не нужно.
- ⚠️ **Ломается:** прямые ссылки `t.me/твойбот/...`, которые ты кидал в переписке раньше, и старые сообщения
  со ссылкой — после перезагрузки они указывают на мёртвый адрес.
- 🔁 Туннель оборвался сам — `run.py` поднимает его заново за секунды (адрес при этом станет новым).

**Вывод:** для игры «для своих» этого более чем достаточно. Правило одно — **точка входа у игроков — кнопка бота,
а не расшаренная ссылка.**

### Нужен постоянный адрес (тоже бесплатно, без белого IP) — именованный туннель + свой домен
Если хочешь адрес, который **не меняется никогда** (можно печатать на визитке и раздавать ссылки), подойдёт
**именованный туннель Cloudflare**. Туннель остаётся бесплатным, белый IP не нужен — платишь только за домен
(**~1–3 $/год**, самое дешёвое вложение в проект).

1. Купи любой дешёвый домен и добавь его в бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com)
   (Add site → следуй подсказкам, смена NS-серверов у регистратора).
2. На самом мини-сервере:
   ```bash
   cloudflared tunnel login                          # откроет ссылку для входа в Cloudflare
   cloudflared tunnel create giftbot                 # создаёт туннель, выдаёт его UUID и файл-креды
   cloudflared tunnel route dns giftbot game.твойдомен.ru
   ```
3. Опиши туннель в `~/.cloudflared/config.yml`:
   ```yaml
   tunnel: giftbot
   credentials-file: /root/.cloudflared/<UUID>.json
   ingress:
     - hostname: game.твойдомен.ru
       service: http://127.0.0.1:8795
     - service: http_status:404
   ```
4. Подними туннель как службу, чтобы стартовал сам после перезагрузки:
   ```bash
   sudo cloudflared service install
   sudo systemctl enable --now cloudflared
   ```
5. В `.env` игры впиши постоянный адрес — тогда `run.py` **не поднимает** случайный туннель:
   ```
   PUBLIC_URL=https://game.твойдомен.ru
   ```
Готово: игра всегда по `https://game.твойдомен.ru/np/`, адрес не меняется даже после сотни перезагрузок.

### Чего избегать
- **ngrok-free, localtunnel и подобные «бесплатные статичные» сервисы** часто показывают страницу-заглушку
  с предупреждением перед сайтом. Mini App грузится в iframe и об эту заглушку спотыкается — игра не откроется.
  Поэтому для постоянного адреса бери домен + Cloudflare, а не их.

### Насколько это надёжно
| Способ | Белый IP | Цена | Адрес | Надёжность |
|---|---|---|---|---|
| Быстрый туннель (по умолчанию) | не нужен | бесплатно | меняется при перезапуске | best-effort, без гарантии, но `run.py` сам переподнимает |
| Именованный туннель + домен | не нужен | ~1–3 $/год (домен) | постоянный | рабочий режим Cloudflare, стабильно |
| VPS с белым IP | есть | ~2–3 $/мес | постоянный | максимально стабильно |

Быстрый туннель — это бесплатный «best-effort» сервис Cloudflare (формально «для тестов»): на практике держится
днями-неделями и сам восстанавливается после обрывов, но 99.9 % аптайма не гарантирует. Для хобби-проекта и
аудитории «для своих» — более чем достаточно. Растёт аудитория и нужна железобетонная стабильность — домен за
доллар или VPS.

### Заметки для одноплатников (Orange Pi / Raspberry Pi)
- **Ставь 64-битную ОС** (Armbian, Ubuntu Server ARM64, Raspberry Pi OS 64-bit). `start.sh` сам подтянет
  ARM64-сборки `cloudflared` и `lego` и поставит зависимости. На 32-битной системе часть пакетов ставится хуже.
- **Памяти хватит с запасом:** игре нужно ~200 МБ, так что 1–4 ГБ RAM — избыток.
- **Береги SD-карту.** База (SQLite в режиме WAL) и бэкапы каждые 6 часов постоянно пишут на диск, а дешёвые
  SD-карты от этого со временем умирают. Варианты: взять карту класса A2/high-endurance **или** грузиться с
  USB-SSD. Главный источник износа — частая запись живой базы (WAL); её можно вынести на внешний диск
  через `.env`, не трогая систему:
  ```
  DB_PATH=/mnt/ssd/game.db
  ```
  Это снимает основную нагрузку на SD-карту. Бэкапы (раз в 6 часов) по-прежнему пишутся в `data/backups/`
  рядом с папкой игры — их редкая запись карту почти не изнашивает; чтобы и они легли на SSD, держи на нём
  всю папку игры целиком.

## ❓ Частые вопросы

**Кнопка «Играть» открывает старую ссылку / «страница не найдена».**
Адрес туннеля меняется при каждом перезапуске — кнопка в меню бота обновляется сама, но старые сообщения бота
со ссылкой перестают работать. Нажимай кнопку меню, а не старые сообщения. Для постоянного адреса без белого IP —
см. раздел «Запуск дома без белого IP» (именованный туннель + домен).

**«Токен не подошёл».** Скопируй токен у @BotFather целиком, без пробелов. Сменить токен — удали строку `BOT_TOKEN` из `.env`.

**Windows ругается «Windows защитила ваш компьютер».** «Подробнее» → «Выполнить в любом случае» — это наш `start.bat`.

**Не запускается туннель.** Проверь интернет; антивирус может блокировать `bin/cloudflared.exe` — добавь в исключения.

**Как перенести игру на другой сервер (всё состояние: игроки, балансы, кланы, СЕЗОНЫ, аватарки — один файл).**

Код приезжает из GitHub (`git clone` + `start`), а данные — отдельным файлом рядом: базу и токен бота **в публичный
репозиторий класть нельзя**, поэтому файл переноса копируешь напрямую (scp / флешка / облако).

Способ А — полный снимок (рекомендую: тянет и загрузки — свои аватарки и баннеры игроков):
1) На старом сервере в папке с игрой: `python snapshot.py` → получишь `np-snapshot-….tar.gz` (база + логи + `u/`).
2) Старый сервер останови (один бот не работает в двух местах). Скопируй архив на новый сервер в папку с игрой
   и переименуй в **`restore.tar.gz`**.
3) На новом: запусти `start` с тем же токеном бота — база и загрузки развернутся **сами**, игра поднимется. Готово.

Способ Б — только база, без копирования файлов на диск (через Telegram):
1) На старом: Админка → «База» → «Экспорт» — бот пришлёт `game-….db.gz` тебе в личку.
2) На новом: запусти `start`, затем Админка → «База» → «Импорт» → этот файл. (Либо положи файл рядом с игрой под
   именем `restore.db.gz` — импортируется сам при старте.) Аватарки/баннеры так не переносятся — для них способ А.

Прежняя база на новом сервере перед заменой всегда сохраняется в `data/backups/`, файл переноса после импорта
помечается `data/imported-…` и повторно не подхватывается.

**Как обновить игру из репозитория.** `git pull` (или скачай ZIP заново, сохранив `data/` и `.env`) → запусти `start`.

**Переводы-чеки через `@имя_бота <сумма>` не появляются в чате.** Включи боту инлайн-режим один раз:
[@BotFather](https://t.me/BotFather) → `/setinline` → выбери бота → задай подсказку (например `сумма чека`). Больше ничего настраивать не нужно — чек спишется с баланса в момент, когда его заберут.

### HTTPS: как выбирается
В `.env` строка `HTTPS=` (по умолчанию `auto`):
- `auto` — сертификат на IP, если получится, иначе туннель;
- `ip` — только сертификат на IP (не вышло — остановиться с ошибкой);
- `tunnel` — всегда туннель Cloudflare.

Сертификат на IP живёт ~6 дней — `run.py` проверяет его дважды в сутки и продлевает сам (ACME-клиент `lego`,
скачивается в `bin/` с проверкой контрольной суммы). Для проверки Let's Encrypt нужен открытый порт 80, для игры — 443.

### Свой домен вместо туннеля
Поставь перед сервером nginx или Caddy с HTTPS, проксируй на `127.0.0.1:8795` и впиши в `.env`:
```
PUBLIC_URL=https://твой-домен
```
Игра будет по адресу `https://твой-домен/np/`, туннель запускаться не будет.

### Работа 24/7 на сервере
Первый запуск `./start.sh` спросит про автозапуск — ответь Enter. Или позже: `venv/bin/python run.py --install`.
